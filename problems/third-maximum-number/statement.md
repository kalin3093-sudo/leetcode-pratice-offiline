You are given an integer array `nums`.

Return the **third distinct maximum** number in this array. If the third **maximum** does not exist, return the **maximum** number.

**Constraints:**

-   `1 ≤ nums.length ≤ 10^4`
-   `-2^31 ≤ nums[i] ≤ 2^31 - 1`

**Follow up:** Can you find an `O(n)` solution?
